# MySQL Least Privilege and Database Security

## Objective

This project demonstrates implementation of least privilege principles in MySQL by restricting unnecessary database access and limiting user permissions.

The goal was to validate secure database access control and prevent unauthorized actions.

## Security Concepts Demonstrated

- Role-Based Access Control (RBAC)
- Principle of Least Privilege
- Restricted Database Permissions
- Database Hardening
- Access Control Enforcement

## Tools Used

- MySQL / MariaDB
- Linux
- SQL Privilege Management
- Command Line Administration

## Key Security Scenarios

### Unauthorized Database Access Denied

Tested restricted database access for unauthorized users.

### Restricted Read Permissions

Validated that users without SELECT permissions could not retrieve sensitive data.

### Restricted Modification Permissions

Confirmed that unauthorized UPDATE operations were blocked successfully.
